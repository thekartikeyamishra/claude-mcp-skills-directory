# Contributing

Thanks for helping keep this list trustworthy. Every skill is scored with the same rubric (see [PLAYBOOK.md](PLAYBOOK.md#6-scoring-methodology-detail)).

## Suggest a skill

Open an issue titled `Add: <skill-name>` with:

- **Link** to the skill folder (not a directory site)
- **What it does** in two or three sentences
- **Install command** you have tested (`npx skills add ...` or `/plugin ...`)
- **The pain it solves**: a concrete failure it prevents, ideally with a before/after example
- **Who uses it** weekly (the ICP)
- **Licence** of the skill
- **Evidence of use** (optional): stars, installs, independent reviews

## Hard gates (auto-reject if any fail)

- No commits or releases in roughly the last 90 days
- Source repository cannot be identified
- Obfuscated scripts or unexplained network calls
- Instructions to hide actions from the user or override prior instructions

## Rules

- One skill per issue.
- Authors may submit their own skills; say so in the issue.
- No paid placement, affiliate links or ranking requests.
- Scores are editorial; disagreements are welcome with evidence.

## Report a problem

Found a broken link, a security concern or a skill that stopped being maintained? Open an issue titled `Review: <skill-name>`. Security concerns are prioritised.
